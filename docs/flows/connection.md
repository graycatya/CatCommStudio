## 3. 各通信模式需要明确的差异

| 场景 | 需要填写的规则 |
| --- | --- |
| 串口 | 打开与关闭、参数校验、端口占用和拔出 |
| TCP 客户端与服务端 | 连接、监听、客户端选择及远端断开 |
| UDP | 本地绑定、目标地址、来源地址；不套用 TCP 已连接状态 |
| BLE | 扫描、连接、服务与特征发现、读写和订阅 |
| USB 与 HID | 设备打开、接口或报告选择、传输结果和设备移除 |

WebSocket、MQTT 在明确范围后再补充对应流程。各模式可按需拆成独立文件并分配流程编号。
