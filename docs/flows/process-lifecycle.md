## 2. 分场景填写

| 场景 | 需要描述的操作 | 需要补齐的分支 |
| --- | --- | --- |
| 创建功能实例 | 启动请求、实例登记、初始化及就绪通知 | 启动失败、初始化失败、超时、重复创建 |
| 打开已有实例 | 识别实例并呈现对应功能 | 实例已退出、功能未就绪、窗口或会话归属不明 |
| 正常关闭 | 关闭请求、任务处理、通信资源释放和退出 | 用户取消、任务未完成、关闭超时 |
| 主进程退出 | 处理现存功能实例及配置 | 是否保留子进程、是否允许独立运行 |
| 子进程异常退出或失联 | 状态反馈、错误记录与恢复入口 | IPC 中断、迟到结果、旧实例消息和重启 |
