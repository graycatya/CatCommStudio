HID 属于已确认的产品通信方向；已核对接口包含普通写入和发送 Feature Report，读取 Feature Report 仍需独立评估。

- 普通写入与发送 Feature Report 的入口和适用条件。
- 设备移除、读写失败、权限限制和配置恢复的处理。

将[单条需求模板](_template.md)从二级标题开始复制到本节下方，以 `REQ-HID-` 为编号前缀。将模板标题改为三级标题、模板内各小节改为四级标题，以保持本文层级。

待填写：逐条记录用户目标、规则、正常与异常流程、验收条件及需求结论。通用规则通过链接引用，模块特有差异在本文件说明。
